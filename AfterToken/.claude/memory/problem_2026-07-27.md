# 问题记录 2026-07-27

## [LobbyUI] 无法添加 GridLayoutGroup 组件（AddComponent 返回 null）

- **问题现象**：从主菜单进入选关界面（LobbyUI）时报错 `[LobbyUI] 无法添加 GridLayoutGroup 组件（AddComponent 返回 null）`，关卡列表布局未生效。Unity Console 前置警告：`Can't add 'GridLayoutGroup' to m_rect_LevelList because a 'VerticalLayoutGroup' is already added to the game object!`
- **根因**：`Assets/AssetRaw/UI/LobbyUI/LobbyUI.prefab` 的 `m_rect_LevelList` 节点上已在编辑器中挂了一个 `VerticalLayoutGroup`（脚本 GUID `59f8146938fff824cb5fd77236b75775`）。`LobbyUI.SetupLevelListLayout()` 只 `GetComponent<GridLayoutGroup>()`（找不到），随后 `AddComponent<GridLayoutGroup>()`；同一 GameObject 不允许同时存在两个 LayoutGroup，Unity 拒绝并返回 null。`AddComponent` 返回 null 不一定代表对象为 null，先查 Console 里 Unity 自身的 "Can't add ..." 警告。
- **修复**：从 Prefab 中移除该 `VerticalLayoutGroup` 组件块及其在 `m_Component` 列表中的引用，让代码按原设计在运行时 `AddComponent<GridLayoutGroup>()` 并配置参数。
- **建议**：UI 布局组件（LayoutGroup 等）以 Prefab 为准、避免编辑器里随手添加与代码逻辑冲突的组件；代码侧如需防御，可先 `GetComponent<LayoutGroup>()` 检查是否存在其它布局组件再决定添加。
- **文档位置**：不涉及 references 错误；属 Prefab 与代码冲突。

## 3D 透视相机下无法根据鼠标位置射击

- **问题现象**：相机方案从 2D 正交改为 3D 俯视（`CameraSystem3D`，透视、60° 俯角）后，射击方向不跟随鼠标/准星。
- **根因**：`InputSystem.HandleAimInput()` 使用 `_mainCamera.ScreenToWorldPoint(aimScreenPos)`，传入 `Vector2` 等价于深度 z=0。正交相机下 z 不影响 x/y 结果所以一直正常；透视相机下 z=0 表示"距相机 0"，返回相机自身位置，瞄准点完全错误。`ProcedureBattle.InitializeBattleSystems()` 会给所有战斗场景相机挂 `CameraSystem3D`，因此新旧场景都受影响。
- **正确 API**：透视相机屏幕坐标转世界坐标用 `Camera.ScreenPointToRay` + `Plane.Raycast` 与玩法平面求交；`ScreenToWorldPoint` 的 z 参数是"距相机的世界深度"，不是世界 z 坐标。
- **修复**：`InputSystem.cs` 的 `HandleAimInput` 改为相机射线与 z=0 的 XY 玩法平面（Rigidbody2D 玩法所在平面）求交，交点 (x, y) 作为瞄准点。正交/透视相机通用。
- **注意**：玩法逻辑（玩家 Rigidbody2D、弹道、敌人）目前仍在 XY 平面；3D 场景的 Ground 是 XZ 视觉地面。若后续把玩法迁移到 XZ 平面，此处的平面定义与 `IWeaponOwner.Position` 的 `(Vector2)transform.position`（取 x/y）都要同步改。

## 相机跟随失效 & 地面无边界 → 玩法层 XY→XZ 整体迁移

- **问题现象**：
  1. 3D 俯视场景下人物越往"下"（世界 -z）走显得越大，且走出一段距离后相机跟不住人物；
  2. 地面没有边界，玩家可以走出地面之外。
- **根因**：
  1. `CameraSystem3D.ApplyRotation()` 计算目标位置时直接 `_followTarget.position + _followOffset`，忽略了 `_yawAngle` 旋转——`_followOffset` 是偏航 0° 时的局部偏移，偏航改变后偏移未随 `Quaternion.Euler(0, _yawAngle, 0)` 旋转，导致相机锚点错误、跟随逐渐失真；"越往下越大"是透视投影下相机锚点偏低/偏后的视觉表现。
  2. 玩法层（玩家、敌人、弹道、弹丸）一直基于 Rigidbody2D 在 XY 平面运算，而 3D 场景的 Ground 是 XZ 平面网格，二者根本不是同一平面，自然没有任何"地面边界"可言。
- **修复（玩法层整体迁移 XY→XZ）**：
  - 新增 `GameLogic.XZConvert`（`Core/Utils/XZConvert.cs`）：玩法层 `Vector2` 语义统一定义为世界 (x, z)，`Vector3.ToXZ()` / `Vector2.ToWorld(y)` 为唯一转换入口；
  - 新增 `System/BattleBoundary.cs`：静态边界，`ProcedureBattle.InitBattleBoundary()` 从场景中名为 "Ground" 的 Renderer.bounds 初始化（margin 0.5f），`PlayerEntity.FixedUpdate` 末尾 `Clamp`，离开战斗时 `Clear()`；
  - 全部 Rigidbody2D → Rigidbody（useGravity=false，constraints=84 即 FreezePositionY|FreezeRotationX|FreezeRotationZ），CircleCollider2D → CapsuleCollider（r=0.3, h=1, center=(0,0.5,0)），弹丸 CircleCollider2D → SphereCollider(r=0.1, trigger) + kinematic Rigidbody；
  - 实体根在 y=0 地面，弹道/视线检测高度统一 0.5f（`BALLISTIC_HEIGHT`/`PROJECTILE_HEIGHT`）；
  - 贴图渲染：Player/Enemy prefab 的 SpriteRenderer 移到新子节点 "Visual"（X+90° 平躺到 XZ 平面）；`EnemyEntity` 取 sprite 改 `transform.Find("Visual")`（避免误取血条 SpriteRenderer）；弹丸/血条等占位视觉仍面朝 -z，俯视下不可见属已知遗留，待美术替换；
  - `InputSystem` 瞄准：相机射线与 `Plane(Vector3.up, Vector3.zero)`（y=0 的 XZ 平面）求交发 (x, z)；顺带修复锁定光标下滚轮恒选 slot 0 的 bug（改用 CrosshairUpdater）；
  - `CameraSystem3D` 重写：`ApplyRotation` 修为目标位置 `targetPos + Quaternion.Euler(0,_yawAngle,0) * _followOffset`；删除滚轮缩放与 Q/E 旋转（与切武器/交互键冲突，仅留鼠标中键拖拽偏航）；接线 `Camera3DConfigMgr`；
  - `BattleSystem` 中对旧 `CameraSystem` 的死引用改走 `CameraSystem3D.Instance?.GetMainCamera()`。
- **遗留**：旧 `CameraSystem.cs`（2D）保留不动，其中仍有一处 `Rigidbody2D` 引用属计划内；2D 老关卡标记为遗留，不再维护。
- **教训**：混合 2D 物理 + 3D 视觉是临时态，一旦确定 3D 俯视角就要尽快把玩法平面统一定义（本项目定为 XZ）并整体迁移，零散的"补丁式适配"会不断产生相机、瞄准、边界类的连环 bug。

## 3D 场景"空无一物" & 人物持续闪烁

- **问题现象**：迁移后进入关卡，Game 视图一片灰色看不到任何物体；人物 sprite 持续闪烁。
- **根因**：
  1. "空无一物"其实是**地面铺满整个视野但没有任何光照**：`BattleScene_3D_L01/L02/L03` 的 RenderSettings 是 `m_AmbientMode: 3`（纯色环境光 (0.212,0.227,0.259)）、无天空盒、无平行光，Ground 用 Standard shader 只吃到这点暗环境光，渲染成均匀暗灰，看起来像空场景。
  2. 人物闪烁是 **z-fighting**：Visual 子节点 localPosition y=0，sprite 平面与地面 Plane 的 y=0 顶面完全共面，深度测试逐帧抖动。
- **修复**：
  1. 三个 3D 战斗场景各添加一个 Directional Light（Euler 50°/-30°，软阴影）；
  2. Player/Enemy prefab 的 Visual 子节点 localPosition 抬到 y=0.05。
- **教训**：任何"贴地平铺"的 2D 视觉（sprite/Quad/贴花）放在 3D 地面上都要留几厘米的 y 偏移，否则必然 z-fighting；3D 场景光照三要素（平行光/环境光/天空盒）缺一时画面会呈现"假空场景"。
