# 战斗模块使用手册（策划版）

> 目标读者：策划、数值、关卡、UI 相关人员。
> 本文档说明如何配置和使用当前俯视角 3D 射击战斗模块，不涉及代码实现细节。
> 2026-08-31 已随 3D 化/Luban 配置化大幅修订；若发现与游戏内表现不符，以 `Configs/GameConfig/Datas/` 下的 xlsx 表与代码为准。

---

## 1. 快速开始

### 1.1 初始化战斗场景与资源

菜单栏选择：

```
Battle → Setup Battle Scene & Resources
```

该工具会自动创建/补齐以下内容：

| 资源 | 路径 | 说明 |
|------|------|------|
| 主菜单场景 | `Assets/AssetRaw/Scenes/MainMenuScene.unity` | 空场景，仅作为流程承载 |
| 基地场景 | `Assets/AssetRaw/Scenes/SimulationScene.unity` | 模拟经营/据点场景 |
| 战斗场景（关卡 101~103） | `Assets/AssetRaw/Scenes/BattleScene_3D_L01~L03.unity` | 3D 俯视战斗场景，相机、光照、地面、出生点、撤离点 |
| 玩家预制体 | `Assets/AssetRaw/Prefabs/Player.prefab` | 青色胶囊（3D），带 `PlayerEntity` |
| 敌人预制体 | `Assets/AssetRaw/Prefabs/Enemy.prefab` | 红色胶囊（3D），带 `EnemyEntity` |
| 普通子弹预制体 | `Assets/AssetRaw/Prefabs/Projectile_Normal.prefab` | 带 `ProjectileEntity` |
| 主菜单 UI | `Assets/AssetRaw/UI/MainMenuUI/MainMenuUI.prefab` | 标题、开始游戏、退出（节点已预置，代码负责绑定事件） |
| 关卡选择 UI | `Assets/AssetRaw/UI/LobbyUI/LobbyUI.prefab` | 选关窗口（基地内 Deploy 按钮/传送门打开，不再是独立场景） |
| 加载过渡 UI | `Assets/AssetRaw/UI/LoadingUI/LoadingUI.prefab` | 场景切换时显示进度条与百分比 |
| 战斗主 UI | `Assets/AssetRaw/UI/BattleMainUI/` | 战斗中 HUD（HP/弹药/武器/撤离倒计时） |
| 狙击镜 UI | `Assets/AssetRaw/UI/SniperScopeUI/SniperScopeUI.prefab` | 开镜全屏遮罩 |
| 武器轮盘 UI | `Assets/AssetRaw/UI/WeaponWheelUI/WeaponWheelUI.prefab` | Tab 轮盘（4 槽） |
| 狙击镜 RenderTexture | `Assets/AssetRaw/Textures/SniperScopeRT.renderTexture` | 512×512 |

> 早期的 2D 场景（`LobbyScene`、`BattleScene`、`BattleScene_L01`~`L03`）已删除，勿再引用。

执行后会自动刷新 YooAsset 编辑器模拟清单。若后续新增了资源或修改了资源路径，建议再执行一次该菜单。

> 注意：`BattleSceneSetup` 对已有 Prefab 采用增量更新，不会删除重建；美术/策划在 Prefab 上的修改会被保留。

### 1.2 运行战斗

当前入口：热更启动后自动进入 `ProcedureMainMenu` 流程，完整流程为：

1. 主菜单场景显示 `MainMenuUI`。
2. 点击"开始游戏"，显示 `LoadingUI` 并加载基地场景（`SimulationScene`），完成后打开 `SimulationMainUI`。
3. 在基地点击 Deploy 按钮或走近选关传送门按 E，打开 `LobbyUI` 选关窗口。
4. 在 `LobbyUI` 中选择关卡后，显示 `LoadingUI` 并加载对应 3D 战斗场景，完成后打开 `BattleMainUI`。
5. 战斗中走进撤离点触发倒计时，倒计时结束撤离回基地；死亡则进入死亡结算。

启动 Play 模式前请确保当前场景为 `Assets/Scenes/main.unity`（包含 `GameEntry` 与 `UIRoot`），不要直接从 `MainMenuScene` 或战斗场景启动。

## 2. 武器配置（weapon.xlsx）

武器数值已由 Luban 配置表驱动：`Configs/GameConfig/Datas/weapon.xlsx`，修改后运行 `Configs/GameConfig/gen_code_bin_to_project.bat` 导表即可生效（无需改代码）。

### 2.1 已配置武器一览

| ID | 名称 | 类型 | 弹道 | 开火模式 | 伤害 | 射速 | 弹匣 | 换弹时间 |
|----|------|------|------|----------|------|------|------|----------|
| 1001 | Pistol | Pistol | Raycast | Single | 15 | 5 | 12 | 1.2s |
| 1002 | SMG | SMG | Raycast | Auto | 8 | 12 | 30 | 1.5s |
| 1003 | Rifle | Rifle | Raycast | Auto | 12 | 8 | 25 | 1.8s |
| 1004 | Sniper | Sniper | Raycast | Single | 80 | 1 | 5 | 2.5s |
| 1005 | Rocket Launcher | Rocket | Projectile | Single | 100 | 1 | 1 | 3.0s |

> 除基础数值外，weapon.xlsx 还包含移动系数（`moveSpeedMultiplier`/`fireMoveSpeedMultiplier`，决定持枪/开火时的移速）、爆炸参数（`explosionRadius`/`explosionDamageFalloff`）、扩散与瞄准等字段，直接在表内查看列头注释。

### 2.2 配置字段说明

#### 基础属性

| 字段 | 类型 | 含义 | 示例 |
|------|------|------|------|
| `id` | int | 武器唯一 ID | 1001 |
| `name` | string | 显示名称 | 手枪 |
| `weaponType` | WeaponType | 武器类型 | Pistol / SMG / Rifle / Sniper / Rocket |
| `ballisticType` | BallisticType | 弹道类型 | Raycast（即时命中）/ Projectile（飞行物） |
| `fireMode` | FireMode | 开火模式 | Single（单发）/ Auto（连发）/ Burst（预留） |
| `damage` | float | 单发基础伤害 | 15 |
| `fireRate` | float | 每秒射击次数 | 5 |
| `clipSize` | int | 弹匣容量 | 12 |
| `reloadTime` | float | 换弹耗时（秒） | 1.2 |
| `maxRange` | float | 最大射程（Raycast） | 20 |

#### 扩散相关

| 字段 | 含义 | 建议 |
|------|------|------|
| `baseSpread` | 基础扩散角度 | 手枪 3°、狙击 0.5° |
| `moveSpreadMultiplier` | 移动时扩散放大倍数 | 通常 1.5~3 |
| `fireSpreadIncrement` | 每开一枪增加的扩散 | 连发武器可设 1~1.5 |
| `spreadRecoveryRate` | 扩散自然恢复速度（每秒减少） | 5~10 |
| `aimSpreadMultiplier` | 瞄准时扩散倍数（<1 为缩小） | 0.1~0.5 |

#### 移动相关

| 字段 | 含义 | 建议 |
|------|------|------|
| `moveSpeedMultiplier` | 持枪移速系数 | 手枪 1.0、狙击 0.7、火箭 0.6 |
| `fireMoveSpeedMultiplier` | 开火时额外移速系数 | 通常 0.5~0.9 |

> 注意：闪避期间不应用任何武器移速系数，保证闪避速度固定。

#### 瞄准相关

| 字段 | 含义 | 建议 |
|------|------|------|
| `aimFov` | 瞄准时相机 FOV | 手枪 50、狙击 25 |
| `aimSensitivityMultiplier` | 瞄准时鼠标灵敏度系数 | 0.4~0.8 |
| `aimAssistEnabled` | 是否启用辅助瞄准磁吸 | 手枪/SMG/步枪 true；狙击/火箭 false |

#### Raycast 弹道视觉

| 字段 | 含义 | 建议 |
|------|------|------|
| `tracerSpeed` | 曳光弹飞行速度 | 40~100 |
| `tracerDelay` | 曳光弹延迟（秒） | 一般 0 |

#### Projectile 弹道（火箭炮）

| 字段 | 含义 | 建议 |
|------|------|------|
| `projectileSpeed` | 飞行物速度 | 火箭 10 |
| `projectileLifeTime` | 最大存活时间 | 5 |
| `projectilePrefab` | 飞行物资源地址（预留） | Projectile_Rocket |
| `explosionRadius` | 爆炸半径 | 3 |
| `explosionDamageFalloff` | 爆炸伤害衰减比例 | 0.5 |

#### 火箭锁定

| 字段 | 含义 | 建议 |
|------|------|------|
| `trackingTime` | 锁定所需时间（秒，预留） | 1.5 |
| `trackingLaserColor` | 锁定激光颜色 | Color.red |
| `lockOnSound` | 锁定音效地址（预留） | SFX_LockOn |

#### 反馈

| 字段 | 含义 | 建议 |
|------|------|------|
| `recoilIntensity` | 后坐力强度，影响相机震动幅度 | 0.3~2 |

#### 资源占位（后续接入）

| 字段 | 用途 |
|------|------|
| `muzzleEffect` | 枪口特效地址 |
| `hitEffect` | 命中特效地址 |
| `fireSound` | 开火音效地址 |
| `reloadSound` | 换弹音效地址 |

### 2.3 新增/修改武器流程

1. 打开 `Configs/GameConfig/Datas/weapon.xlsx`。
2. 复制一行现有武器，修改 `id`（必须唯一）。
3. 调整数值，重点确认：
   - `ballisticType` 与 `fireMode` 是否匹配玩法预期。
   - `aimFov` 与 `weaponType`：狙击枪建议 25，其他 35~55。
   - 火箭炮类需填写 `projectileSpeed`、`projectileLifeTime`、`explosionRadius`。
4. 运行 `Configs/GameConfig/gen_code_bin_to_project.bat` 导表。
5. 让玩家持有：关卡默认武器在 `level.xlsx` 的 `defaultWeaponIds` 列配置（战斗开局带入）。
6. Play 测试。

## 3. 敌人配置

敌人生成参数（数量/半径/配置 ID/最大血量）由关卡表 `level.xlsx` 的 `enemyCount`、`enemySpawnRadius`、`enemyConfigId`、`enemyMaxHp` 列按关卡配置，运行时 `EnemySpawnSystem` 读取当前关卡配置生成。敌人基础属性见敌人表（`enemy.xlsx`，如 9001 训练假人）。

### 敌人预制体

- 路径：`Assets/AssetRaw/Prefabs/Enemy.prefab`
- 默认：红色 3D 胶囊，Rigidbody + CapsuleCollider，已挂载 `EnemyEntity`。
- 替换外观：直接在该预制体上替换模型/颜色/大小即可。
- 注意：不要移除 `EnemyEntity` 和 CapsuleCollider。

## 4. 关卡配置（level.xlsx）

关卡表由 Luban 驱动：`Configs/GameConfig/Datas/level.xlsx`，修改后运行 `gen_code_bin_to_project.bat` 导表生效。

### 4.1 已配置关卡一览

| ID | 显示名 | 场景 | 敌人数量 | 生成半径 | 敌人最大 HP | 撤离倒计时 | 默认武器 |
|----|--------|------|----------|----------|-------------|------------|----------|
| 101 | 3D Training Ground L1 | `BattleScene_3D_L01` | 10 | 12 | 50 | 10s | 1001, 1003, 1004, 1005 |
| 102 | 3D Abandoned Factory L2 | `BattleScene_3D_L02` | 15 | 12 | 80 | 10s | 1002, 1003, 1004 |
| 103 | 3D Boss Arena L3 | `BattleScene_3D_L03` | 20 | 14 | 100 | 10s | 1002, 1003, 1004 |

> 撤离倒计时为 `extractionTime` 列：玩家进入撤离点范围后开始倒计时，归零且存活即撤离回基地。

### 4.2 调整方法

1. 打开 `level.xlsx`，修改对应 `id` 的字段。
2. 运行 `Configs/GameConfig/gen_code_bin_to_project.bat` 导表。
3. Play 测试。

### 4.3 新增关卡工作流

1. 在 `level.xlsx` 中新增一行，指定唯一的 `id` 与 `sceneName`。
2. 创建场景文件 `Assets/AssetRaw/Scenes/{sceneName}.unity`（可复制 `BattleScene_3D_L01.unity`），场景中需包含出生点、撤离点等实体。
3. 将该场景加入 `File → Build Settings → Scenes In Build`。
4. 运行导表脚本，并执行 `Battle → Setup Battle Scene & Resources` 刷新 YooAsset 模拟清单。
5. 在基地的 `LobbyUI` 选关窗口中即可看到新关卡按钮。

## 6. 输入配置

键位已支持玩家自定义：游戏内 `Settings → Input` 页签可改绑按键（保存在本地设置）。默认键位：

| 功能 | 输入 | 说明 |
|------|------|------|
| 移动 | WASD / 方向键 | `Horizontal` / `Vertical` 轴 |
| 瞄准 | 鼠标位置 | 鼠标在世界坐标中的位置 |
| 开火 | 鼠标左键 | 按住连发、单发点射 |
| 瞄准/开镜 | 鼠标右键 | 狙击枪开镜（Hold/Toggle 模式在 Settings 中切换） |
| 换弹 | R | 进入换弹状态 |
| 武器切换 | 鼠标滚轮 | 上下切换槽位 |
| 武器轮盘 | 按住 Tab | 时间变慢，松开后选中高亮武器 |
| 闪避 | Space | 向当前移动方向翻滚 |
| 小地图放大 | M | 全屏小地图开关 |

> 准星样式/颜色、灵敏度、狙击开镜模式（Hold/Toggle）均可在 Settings 界面调整。

## 7. UI 配置

### 7.1 分辨率与适配

- 锁定分辨率：1920×1080，16:9。
- 独立全屏 UI（`MainMenuUI`、`LobbyUI`、`LoadingUI`、`BattleMainUI`）嵌套在 `UIRoot/UICanvas` 下，运行时由 `UIWindow.FixFullScreenCanvas()` 统一修复 Canvas 缩放，无需在 prefab 中手动维护 `CanvasScaler`。
- `SniperScopeUI`、`WeaponWheelUI`、`HitFeedbackSystem` 仍使用 `CanvasScaler`：
  - `Scale Mode`：Scale With Screen Size
  - `Reference Resolution`：1920 × 1080
  - `Screen Match Mode`：Match Width Or Height
  - `Match`：0.5

### 7.2 主菜单 `MainMenuUI`

- 路径：`Assets/AssetRaw/UI/MainMenuUI/MainMenuUI.prefab`
- Prefab 节点：
  - `m_text_Title`：标题文本，默认 "AfterToken"。
  - `m_rect_ButtonRoot`：按钮根节点，带 `VerticalLayoutGroup`。
    - `m_btn_Start`：开始游戏按钮。
    - `m_btn_Exit`：退出游戏按钮。
- 运行时逻辑：代码通过 `ScriptGenerator` 绑定节点并注册点击事件。
- 调整：
  - 文本/颜色/布局：直接修改 Prefab。
  - 按钮行为：联系程序修改 `MainMenuUI.cs`。

### 7.3 关卡选择 `LobbyUI`

- 路径：`Assets/AssetRaw/UI/LobbyUI/LobbyUI.prefab`
- 打开时机：基地内点击 Deploy 按钮或交互选关传送门（纯 UI 窗口，不再有独立的 Lobby 场景/流程）。
- Prefab 节点：
  - `m_text_Title`：标题文本。
  - `m_rect_LevelList`：关卡按钮列表根节点，带 `VerticalLayoutGroup`。
    - `m_btn_LevelTemplate`：关卡按钮模板（运行时克隆，默认隐藏）。
  - `m_btn_Back`：返回按钮。
- 运行时逻辑：代码读取关卡表（`level.xlsx`），按 `id` 排序后克隆模板生成按钮。
- 调整：
  - 按钮样式/布局：直接修改 Prefab。
  - 关卡数据：修改 `level.xlsx` 并导表。

### 7.4 加载过渡 `LoadingUI`

- 路径：`Assets/AssetRaw/UI/LoadingUI/LoadingUI.prefab`
- 层级：`UILayer.System`，确保覆盖在所有普通 UI 之上。
- 触发时机：每个 Gameplay 流程切换场景时自动打开，场景加载完成后关闭。
- 进度更新：`LoadingUI.SetProgress(progress)`，其中 `progress` 为 0~1。

### 7.5 战斗主界面 `BattleMainUI`

- 路径：`Assets/AssetRaw/UI/BattleMainUI.prefab`
- 运行时自动生成左上角信息面板，包含：
  - HP 文本
  - 弹药文本
  - 武器名称文本
- 调整位置/大小：当前为代码动态生成，需联系程序修改 `BattleMainUI.BuildInfoPanel()`。

### 7.6 狙击镜 `SniperScopeUI`

- 路径：`Assets/AssetRaw/UI/SniperScopeUI/SniperScopeUI.prefab`
- 触发条件：持有 `weaponType = Sniper` 的武器并开镜。
- 表现：全屏黑色遮罩，中心圆形视野显示放大画面；命中敌人时出现 X 型命中标记（命中后自动清除）。
- 可调参数（代码，`CameraSystem3D`）：
  - 狙击镜 RenderTexture 尺寸，默认 512。
  - 镜内相机 `fieldOfView`，默认 25。

### 7.7 武器轮盘 `WeaponWheelUI`

- 路径：`Assets/AssetRaw/UI/WeaponWheelUI/WeaponWheelUI.prefab`
- 触发条件：按住 `Tab`。
- 表现：4 个扇区（对应 4 个武器槽），每个扇区显示武器图标与名称，悬停显示武器属性。
- 选中逻辑：以屏幕中心为原点，按鼠标角度均分扇区。

### 7.8 命中反馈 `HitFeedbackSystem`

- 不是独立 UI 预制体，运行时自动创建。
- 表现：
  - 屏幕中心命中标记（命中时闪红/橙 0.15s）。
  - 8 方向受击指示器（N、NE、E、SE、S、SW、W、NW），显示伤害来源方向。
- 可调参数：
  - `_indicatorShowDuration`：指示器显示时长，默认 1s。
  - `_indicatorFadeSpeed`：淡出速度，默认 2。

## 8. 场景配置

### 8.1 启动场景 `main`

- 路径：`Assets/Scenes/main.unity`
- 必须包含 `GameEntry`（框架入口）与 `UIRoot`（全局 UI 根，DontDestroyOnLoad）。
- 所有流程均从该场景启动，战斗/菜单场景通过 `GameModule.Scene.LoadSceneAsync` 切换。

### 8.2 主菜单场景 `MainMenuScene`

- 路径：`Assets/AssetRaw/Scenes/MainMenuScene.unity`
- 当前为空场景，`ProcedureMainMenu` 负责加载并显示 `MainMenuUI`。

### 8.3 基地场景 `SimulationScene`

- 路径：`Assets/AssetRaw/Scenes/SimulationScene.unity`
- 模拟经营/据点场景：建筑摆放、NPC（对话/任务）、仓库、选关传送门均在此。
- 进入方式：主菜单"开始游戏"，或战斗撤离/传送门返回。

### 8.4 战斗场景 `BattleScene_3D_L01`~`L03`

- 路径：`Assets/AssetRaw/Scenes/BattleScene_3D_L01.unity`（L02/L03 同理）
- 默认包含：
  - `Main Camera`：透视相机（俯仰 60°、FOV 45，运行时由 `CameraSystem3D` 按 `camera3d.xlsx` 统一接管，勿在场景里手调）。
  - 方向光。
  - `Ground`：网格地面（1 米 1 格），带 3D Collider。
  - `PlayerSpawnPoint`：玩家出生点。
  - 撤离点（`ExtractionPoint`）、战利品箱、小纸条等玩法实体按关卡摆放。

### 8.5 调整场景边界

1. 选中 `Ground`。
2. 在 Inspector 中调整地面缩放与 Collider 尺寸。
3. 注意保持渲染与碰撞尺寸一致；地面边界即玩法边界，请勿让玩家能走出地面。

### 8.6 Layer 与 Tag

当前战斗使用以下 Layer，请勿随意修改名称：

| Layer | 用途 |
|-------|------|
| Player | 玩家 |
| Enemy | 敌人 |
| Projectile | 飞行子弹 |

## 9. 弹道与命中

### 9.1 Raycast 武器

- 适用：手枪、冲锋枪、步枪、狙击枪。
- 命中检测：3D 物理 Raycast/CircleCast，命中层为 `Enemy` 和 `Obstacle`。
- 视觉：曳光弹飞向命中点。
- 配置重点：`damage`、`fireRate`、`maxRange`、`baseSpread`、瞄准相关字段。

### 9.2 Projectile 武器

- 适用：火箭筒（Rocket Launcher）。
- 飞行物：火箭弹预制体（weapon.xlsx 的 `projectilePrefab` 列，如 `Projectile_Rocket`）。
- 飞行方式：**直线飞行**，命中或寿命终点引爆；无索敌/追踪（锁定功能已移除）。
- 命中检测：每帧 Cast，避免穿墙。
- 爆炸：按 `explosionRadius` 和 `explosionDamageFalloff` 计算范围伤害；爆炸特效为 shader 实现的火球+冲击波。
- 激光瞄准线常开，从武器枪口射出。

## 11. 常见工作流

### 11.1 调整一把武器的数值

1. 打开 `Configs/GameConfig/Datas/weapon.xlsx`。
2. 修改对应 `id` 行的数值。
3. 运行 `Configs/GameConfig/gen_code_bin_to_project.bat` 导表。
4. Play 测试。

### 11.2 新增一把武器

1. 在 `weapon.xlsx` 中新增一行 `id` 唯一的配置。
2. 在 `level.xlsx` 的 `defaultWeaponIds` 列把武器加进关卡默认装备。
3. 若是 Projectile 武器，确保填写 `projectileSpeed`、`projectileLifeTime`、`projectilePrefab` 等字段。
4. 如需独立外观，制作新的子弹/武器预制体并配置地址。
5. 导表后 Play 测试。

### 11.3 替换玩家/敌人外观

1. 打开对应预制体（`Player.prefab` 或 `Enemy.prefab`）。
2. 替换模型、颜色、大小。
3. 如需动画，添加 `Animator` 组件并制作状态。
4. 保存预制体，Play 测试。

### 11.4 调整敌人生成

1. 打开 `level.xlsx`，修改对应关卡的 `enemyCount`、`enemySpawnRadius`、`enemyConfigId`、`enemyMaxHp` 列。
2. 导表后 Play 测试。

### 11.5 新增或调整关卡

1. 打开 `Configs/GameConfig/Datas/level.xlsx`，修改现有关卡字段，或新增一行 `id` 唯一的配置并指定 `sceneName`。
2. 若新增场景，复制 `BattleScene_3D_L01.unity` 并重命名为 `sceneName`。
3. 将新场景加入 `File → Build Settings → Scenes In Build`。
4. 导表，并执行 `Battle → Setup Battle Scene & Resources` 刷新模拟清单。
5. Play 测试，确认基地 `LobbyUI` 出现新关卡按钮且能正常进入战斗。

### 11.6 调整 UI 位置

- 所有 UI 均为预制体（`Assets/AssetRaw/UI/` 下），可直接在 prefab 中调整布局、颜色、大小、层级。
- 注意新建 UI prefab 根节点必须挂 `Canvas` + `GraphicRaycaster`；改完 `AssetRaw` 后需重新执行 `Battle → Setup Battle Scene & Resources`（或手动 SimulateBuild）刷新模拟清单。

## 12. 注意事项

- 当前没有接入真正的音效系统，`fireSound`、`reloadSound`、`muzzleEffect`、`hitEffect` 字段为预留（爆炸特效已 shader 化，不走这两个字段）。
- 武器/关卡/敌人等数值均已接入 Luban 配置表（`Configs/GameConfig/Datas/*.xlsx`），改表后必须运行 `gen_code_bin_to_project.bat` 导表才生效。
- 相机参数（俯仰角/偏移/FOV/缩放范围）统一由 `camera3d.xlsx` 驱动，战斗与经营场景同源，不要在场景里手调相机。
- 不要删除或重命名 `PlayerSpawnPoint`，否则玩家出生位置会回到世界原点。
- 若修改了 Layer 名称，务必同步修改代码中 `LayerMask.NameToLayer("...")` 的引用，否则命中检测会失效。
- Play 模式必须从 `Assets/Scenes/main.unity` 启动，`UIRoot` 为 `DontDestroyOnLoad`，直接从 `MainMenuScene` 或战斗场景启动会导致 UI 加载失败。
- 新增或修改 `Assets/AssetRaw/` 下的资源后，需执行 `Battle → Setup Battle Scene & Resources` 刷新 YooAsset 编辑器模拟清单。
